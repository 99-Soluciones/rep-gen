# repgen-frontend

Interfaz de RepGen: React, Vite, AG Grid y Tailwind.

- Instalación, scripts y deploy: [README raíz](../README.md).
- Variables de entorno (`.env`): `VITE_API_URL` (por defecto `/api/v1`) y `DEV_API_PROXY_TARGET` (backend al que reenvía el proxy de desarrollo; por defecto `http://localhost:3000`).
- Diseño y producto: [DESIGN.md](DESIGN.md) y [PRODUCT.md](PRODUCT.md).
- Vistas guardadas: [docs/MODULO_CONFIGURACIONES_COLUMNAS.md](docs/MODULO_CONFIGURACIONES_COLUMNAS.md). El resto está en el [índice general](../docs/README.md).
